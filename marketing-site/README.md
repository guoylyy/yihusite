# 公司营销案例站点

这是我们的“项目案例库 / 营销落地页”站点。  
目标：给潜在客户看我们真实做过什么，多少钱，多久交付，能带来什么价值，并且一键加我微信沟通需求。

## 运行环境
- Node.js >= 20.9.0
- Next.js 16 + App Router
- Tailwind CSS 4.x
- TypeScript 5.x

## 本地启动
```bash
npm install
npm run dev
# 浏览器打开 http://localhost:3000
```

## 部署
这个项目通过 `generateStaticParams` 预生成每个案例详情页，
可以非常轻松地放在 Vercel 部署，或者用 `npm run build && npm start` 在你自己的服务器上跑。

## 我怎么加一个新案例？
1. 打开 `lib/cases.ts`，按现有 `demoCase` 的格式，复制一份，改内容，改 slug。
2. 往 `public/cases/<你的slug>/` 里放截图和演示视频。
3. 确保 `public/qr/wechat.png` 是你的微信二维码。
4. 提交代码并重新部署。站点会自动多出一个新 URL：`/cases/<你的slug>`。
5. 把这个新链接发给客户 / 发朋友圈引流。

## 发朋友圈的玩法
- 朋友圈正文写：客户痛点 → 我们怎么解决 → 效果（最好能用具体指标，例如“从2小时降到10分钟”）。
- 配上关键界面截图 + 你的二维码。
- 引导语示例：“想做类似系统？扫码看详细功能和大概预算”。
